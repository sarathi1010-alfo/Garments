# CORE EXECUTION RULES

1. Never generate low-quality AI spam.
2. Never publish duplicate or near-duplicate content.
3. Never create unrelated or random-topic pages.
4. Never use keyword stuffing.
5. Never publish thin content.
6. Never break schema or internal link structure.
7. Maintain semantic consistency across the entire site.
8. Prioritize long-term authority over short-term traffic spikes.
9. Every page must provide real value and practical usefulness.
10. Content must feel natural, human-written, readable, and experience-based.
